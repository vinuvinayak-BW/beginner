# beginner
This repository contains beginner-level code.

## Four-Digit Combination Generator

A small Python script that prints every four-digit combination from `0000` through `9999`, including leading zeroes.

## Run

```sh
python crack.py
```

The script writes each combination to the terminal; it does not attempt to test them against a device, account, or service. Use generated combinations only in systems and test environments you own or are explicitly authorized to assess.
